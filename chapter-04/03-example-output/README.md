# Example output

`SOP-003-New-Client-Onboarding.md` is the procedure as it came out of the chapter,
after the interview, the write step, and one round of team feedback. It is unedited
except for house punctuation, so it still carries what a real second draft carries:
four [TO CONFIRM] markers for facts nobody in the room knew, four [OWNER DECISION]
markers for the questions the managing partner has to settle, and one tagged conflict
over the order of the welcome email and the client record.

That is the point of showing it. A procedure at this stage is useful and unfinished at
the same time, and the markers are what make it safe to hand to someone: they show
exactly where the document stops knowing things.

`sop-index.csv` is the index spreadsheet with the eight columns from the chapter.
SOP-003 sits at status draft, because it is still in the review loop. SOP-002 is
deliberately more than six months past its last review, so the monthly audit prompt
returns something the first time you run it. Delete all five rows before you use the
sheet for real, and keep the header.
