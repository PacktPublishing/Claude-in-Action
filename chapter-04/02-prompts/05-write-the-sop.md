Send this once the interview questions have run out and you have answered them all.
Paste the contents of sop-template.md underneath it, or attach the file.

---

Write the full SOP now, using this template exactly.
Keep every step to one action starting with a verb.
Write decision points as: condition, then the path for
each outcome. List every edge case we discussed with
its symptom and response. Mark anything we left
unresolved with [TO CONFIRM].
