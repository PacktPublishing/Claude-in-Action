# Maintenance prompts

The ten minutes a month the chapter budgets for. Run these in the scheduled
task's own conversation, or edit the instructions directly on the Scheduled
page.

## A channel changed

    Update my digest instructions: replace #client-aurora with #client-halden in the Slack sources. Leave everything else unchanged and show me the revised instruction block before saving.

## The digest is too long

    My last three digests ran past one page. Tighten the filters rather than the writing: suggest which of my current sources or priority levels is producing the most lines, and propose one change.

## A source is missing from the output

    Yesterday's digest had no Slack section. Check whether the connector is still signed in, then tell me what you can and cannot read in #client-aurora and #delivery right now.

## Someone new joined the team

    Add [name] to the workload note in my digest instructions. Show me the revised format block before saving.

## Check the run history

    Show me the run history for my Monday digest task: which runs fired on time, which ran late, and which produced no output.
