# Digest instructions: the individual contributor version (Amara)

Same structure as the manager version. Every source narrows to one person, and
meetings move to the top of the priority list, because a meeting in two hours
outranks a task due Thursday when nobody is waiting on you to unblock them.

Nothing in this prompt says when to run it. You set the frequency and the day on
the scheduled task itself, under Frequency.

---

Build this digest.

Sources:
- ClickUp: all tasks assigned to me that are overdue or due in the next 7 days, with status
- Slack: threads in #client-aurora and #delivery where I am mentioned or asked a direct question, from the last 7 days
- Google Calendar: my meetings this week, flagging any with external attendees
- Gmail: emails from the last 7 days still waiting on a reply from me

Order the digest by urgency, not by source:
1. Meetings in the next 48 hours that need preparation
2. Overdue tasks, oldest first
3. Questions waiting on my answer
4. Emails waiting on my reply for more than 3 days
5. Everything else, grouped by project

Skip: resolved threads, newsletters, calendar holds without attendees, and tasks in the Backlog list.

Format:
- Open with a 3-sentence summary of the week ahead
- One section per priority level, as bullet points with links back to the source items
- Keep the whole digest under one page
- Save it as a Markdown file named with today's date in my Documents/Digests folder
