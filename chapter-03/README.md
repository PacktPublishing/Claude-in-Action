# Chapter 3 sample pack: Interview Guide Generator

Everything you need to build the hiring project from Chapter 3. The company, the role, and all three candidates are fictional, created for this book.

The folders match the four places this material goes.

| Folder | What you do with it |
| --- | --- |
| `01-project-instructions/` | Copy the text into the project's custom instructions field |
| `02-project-context/` | Upload all seven files to the project context, once |
| `03-chat-inputs/` | Attach these to an individual chat, one hire at a time |
| `04-answer-key/` | Check your results afterwards |

Each folder has its own README with the detail.

## Order of work

1. Create a project called Hiring.
2. Paste `01-project-instructions/project-instructions.txt` into the custom instructions.
3. Upload the seven files in `02-project-context/` to the project context.
4. Open the two job description files in `03-chat-inputs/` side by side and read them. The careers-page version is what most companies publish; the marked-up version is what produces a usable guide.
5. Start a new chat inside the project. Attach `JD-Marketing-Specialist.md` and one CV. Follow the chapter from there.
6. Run all three candidates before opening `04-answer-key/`. Each one exercises a different part of the guide.

## One rule that matters

CVs go in the chat, never in the project context. A chat is one place you can find and delete. Chapter 3 covers the reasoning, and Chapter 11 covers the obligations behind it.
