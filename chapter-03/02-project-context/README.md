# Project context

Seven files. Upload all of them to the Hiring project's context, once. Every chat you start inside the project can then read them, so you never paste this context again.

| File | What it gives the generator |
| --- | --- |
| `company-overview-and-values.md` | Who Brightpath is and what it cares about, so questions reflect the company |
| `writing-and-communication-style.md` | How the questions should sound |
| `hiring-philosophy.md` | Why questions come from the role and probes from the CV |
| `recruiting-process-sop.md` | Where the guide sits in the wider hiring process |
| `role-success-profile-marketing-specialist.md` | The three priorities and the knockout criteria |
| `job-description-template.md` | The skeleton for the next role you open |
| `interview-scorecard-and-decision-framework.md` | The 1 to 4 scale, the rubric tests, and the decision rule |

Later in the chapter you add an eighth file here: the reusable interview template you build for this role.

Candidate CVs never go in this folder, and never go into the project context. Chapter 3 explains why.
