# Job description template

Brightpath Analytics is the fictional company used throughout Chapter 3. Add this file to the Hiring project context.

A reusable skeleton for any role. Fill the brackets, then mark requirements as must-have or nice-to-have.

```
Note to the interview guide generator:
The three priorities for this hire, in order:
1. [priority]
2. [priority]
3. [priority]
Everything else below is context. Questions come from these three.

Role title: [title]
Team and manager: [team], reporting to [manager]
Location and hours: [location], [working hours]

About [company]: [two lines on what the company does]

In a typical month you will:
- [responsibility, with the number or the tool attached]
- [responsibility, with the number or the tool attached]
- [responsibility, and what someone else does instead]

Must-have (we cannot consider candidates without these):
- [knockout requirement]
- [knockout requirement]

Nice-to-have (a plus, not required):
- [preferred qualification]
- [preferred qualification]

How we hire: [short note on the structured process]
What we offer: [salary band, benefits, growth]
```
