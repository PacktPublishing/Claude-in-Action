# Writing and communication style

Brightpath Analytics is the fictional company used throughout Chapter 3. Add this file to the Hiring project context.

How we write, including in interview guides and candidate correspondence.

- Short sentences. One idea per sentence.
- Plain words over industry vocabulary. If a customer would not use the word, we do not either.
- Numbers instead of adjectives. "Cut cost per lead by 22 percent" rather than "significantly improved performance".
- Direct address. We write to a person, not about a process.
- No filler openings. We start with the point.
- Questions we ask candidates are written the way we would say them out loud.
