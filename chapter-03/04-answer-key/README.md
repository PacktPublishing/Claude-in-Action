# Answer key

Read these after you have run the candidates, not before.

| File | What it is |
| --- | --- |
| `answer-key.md` | The verdict and priority marks each candidate should produce, plus what to check if yours came out different |
| `reference-interview-template.md` | A finished version of the reusable template you build near the end of the chapter |

The chat-inputs README has a one-paragraph summary of each candidate if you want the short version before you run them.

Your wording will not match. What should match is the structure: the knockout verdict, which priorities come back strong or thin, and whether a guide gets written at all.

When you are happy with your own template, move it to `02-project-context/` so future chats in the project can use it.
