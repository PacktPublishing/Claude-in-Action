# Chapter 6 materials: Monitoring your competitors with a live intelligence board

Everything you need to build the board from the chapter, against your own competitors.

## What is here

- `01-project-folder/` the three files that go in your `competitor-board` folder
- `02-prompts/` every prompt from the chapter, in the order you run them
- `03-samples/` what the output looks like, so you can compare
- `04-answer-key/` the decisions behind the example, and how to make the same ones for your niche

## Before you start

- A Claude Team plan seat where your admin has allowed the vidIQ connector, or a Pro account where you can add connectors yourself
- A vidIQ account with MCP access, set up from vidiq.com/mcp
- Three to five competitor YouTube channels

## A note on the example files

Wildgrass Yoga and its three competitors are fictional. The channel URLs in `competitors.csv` do not exist, and `our-channel-export-SAMPLE.csv` contains made-up numbers. They are there to show you the shape of each file.

Replace all three with your own before you run anything. If you do not run a YouTube channel, pick three public channels in a niche you know, write positioning notes for a business you understand, and delete the channel export.
