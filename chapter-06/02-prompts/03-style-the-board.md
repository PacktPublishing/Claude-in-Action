# Prompt 3: style the board

```
Turn the competitor cards into a single dashboard artifact in
Neobrutalism style: thick black borders, hard offset shadows,
flat color blocks, no gradients, bold sans-serif headings.
Give each competitor card its own accent color. Place our own
channel's card at the top, visually distinct from the rest.
Add a "last refreshed" date stamp to every card.
```

Keep the date stamp whatever else you change. A board with no visible refresh date is indistinguishable from the stale report this project replaces.

Swapping Neobrutalism for another style is fine. Replace the second and third lines with your own description and leave everything from `Give each competitor card` onward as it is.
