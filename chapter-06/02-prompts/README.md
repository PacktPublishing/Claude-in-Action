# The prompts

Run these in order, in one Cowork session pointed at your `competitor-board` folder.

1. `01-confirm-folder.md` makes Claude tell you what it can see before anything else happens
2. `02-competitor-breakdown.md` builds one card per competitor
3. `03-style-the-board.md` turns the cards into the dashboard
4. `04-combined-trend-view.md` adds the cross-competitor section above the cards
5. `05-standing-refresh-instruction.md` makes "refresh the board" a standing command

Prompts 2 to 4 each produce something you should read before moving on. The card structure in particular is worth fixing early, since every later refresh reuses it.

Replace nothing in these prompts except where a line is marked. The file names inside them must match the file names in your folder.
