# Prompt 1: confirm the folder

Point the session at your `competitor-board` folder when Claude asks for a working directory, then run:

```
List the files in this folder and summarize what each one contains.
```

You are looking for three files by name, and a one-line summary of each that matches what you actually wrote. If Claude describes a file you do not recognize, or misses one, fix that before running anything else.
