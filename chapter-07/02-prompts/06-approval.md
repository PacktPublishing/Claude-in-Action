# Prompt 6: the approval gate

When the skill stops, work through three questions before you approve anything.

**Does the order survive what you know and the data does not?** For the Silverpine example, assume the sync fix is two days of work and deposits is a quarter-long build:

```
Mark calendar sync reliability as the top priority and note that
deposits remains the largest single request.
```

Claude should apply the change and show you the revised roadmap before doing anything else.

**Do the evidence groups say what Claude claims?** Spot-check one item per tier against the sheet.

**Is anything identifying?** Look for quotes that point at one customer without naming her. The Silverpine data has one on purpose: a two-person salon in the old town square.

**Confirm or reject the deferral suggestions.** Items under "Suggested for deferral" move to "Declined or deferred" only when you say so. For the example:

```
Confirm group class bookings as deferred, not this quarter.
```

Then approve:

```
Approved, build the deck.
```

Claude overwrites the saved roadmap with the approved version and only then builds the presentation.
