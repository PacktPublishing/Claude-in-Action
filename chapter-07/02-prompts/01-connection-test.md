# Prompt 1: connection test

With the toggle set to Cowork:

```
Open the Google sheet called "Silverpine Feedback Form Responses"
and tell me how many responses it contains and the date range.
```

Expected answer: 189 responses, April 1 to June 26, 2026.

If Claude cannot find the sheet, check that it sits in the Drive of the connected Google account and that the name matches exactly. A converted CSV keeps the CSV's file name until you rename it.

Use this test on your own data too: ask something whose answer you already know before you ask something whose answer you do not.
