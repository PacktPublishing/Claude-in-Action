# The prompts

Run these in order, in one Cowork session with `silverpine-roadmap` selected as the working folder.

1. `01-connection-test.md` confirms Claude can reach the sheet
2. `02-theme-extraction.md` runs the analysis in the open, before any skill exists
3. `03-one-fix-test.md` is the correction to add when Claude merges or splits themes wrongly
4. `04-build-the-skill.md` turns the analysis into the `roadmap-builder` skill
5. `05-trigger-test.md` checks the skill fires
6. `06-approval.md` covers what to say at the approval gate
7. `07-update.md` runs the update loop on the July batch
8. `08-dispatch.md` builds the deck from your phone

If you are using your own data, four things change: the sheet name, the column letters, the folder name, and the top of the emotion scale. All four sit in prompts 2 and 4.
