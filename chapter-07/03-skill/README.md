# Reference skill

`roadmap-builder/SKILL.md` is a reference copy, assembled from the excerpts in the chapter. It is not the file you are meant to install.

Build your own with prompt 4, then compare. Claude's wording will differ, and that is fine. What has to match is the behaviour: the folder check and full read of the previous roadmap, the three-respondent rule, the STOP before any presentation, the deferral rule, and the presentation structure.

One addition in this copy: step 3 includes the one-fix test from `02-prompts/03-one-fix-test.md`. If your audit needed that correction, your skill should carry it too.

If you would rather install this copy directly, place the `roadmap-builder` folder inside your `silverpine-roadmap` folder.
