# Samples

What the outputs look like on the Silverpine sheet. The counts and row numbers are the real ones for the sample data. Theme names, wording and layout will differ in your run.

- `sample-theme-analysis.md` the result of the extraction prompt, before any skill exists
- `sample-roadmap-Q2-draft.md` the draft the skill saves and shows you at the gate
- `sample-roadmap-Q2-approved.md` the same file after you reorder P1 and confirm the deferral
- `sample-deck-outline.md` the seven slides the approved roadmap produces, with speaker notes
