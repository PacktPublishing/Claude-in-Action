# Adapting the workflow to your own feedback

## Four things to change

| What | Where | Silverpine value |
|---|---|---|
| Sheet name | Prompt 1, prompt 2, the skill's workflow step 1 | Silverpine Feedback Form Responses |
| Column letters | Prompt 2 and the skill's workflow step 3 | Free text F, G, H; context B, C |
| Folder name | Your Cowork working folder and the Dispatch prompt | silverpine-roadmap |
| Top of the emotion scale | Prompt 2, rule 5 | Lost revenue or a threat to leave |

## Shaping your sheet

- One response per row
- Free text in its own column, one or two open questions at most
- A date on every row, formatted as a date, not text
- A few structured questions (business type, tenure, plan) so themes can be segmented
- An optional email column with consent, which is the only way to spot repeat respondents

## Feedback from other places

Survey exports (Typeform, SurveyMonkey) import into Google Sheets through **File | Import**. App store or marketplace reviews work the same way: paste them into a sheet with a date column and a text column.

## Before you connect anything

Run the five-question compliance check from Chapter 1. At minimum, write down who can see the outputs, which identifying details must be stripped, and how long generated files are kept. Those answers go into the skill's rules.
