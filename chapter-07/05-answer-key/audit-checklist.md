# Audit checklist

Run this on the first analysis and after any change to the prompt. About ten minutes on 189 rows.

1. Pick two themes. Open every cited row in the sheet and check the theme is actually mentioned there.
2. Check each quote exists, word for word, in the row it cites.
3. Compare the mention count with the rows listed. They should be the same number.
4. Compare mentions with distinct respondents. Where they differ, find the repeated email addresses.
5. Open the row cited for the strongest emotion and check it earns the rating: lost revenue or a threat to leave for a 5.
6. Look for two problems sharing one theme. If one fix would not resolve both, add the one-fix test to the prompt.
7. Look for one problem split across two themes. Same test, other direction.
8. Read the weak signals list for anything that deserved better.
9. Read every quote that would reach the deck and ask whether it identifies a customer without naming her.
10. Start once from the sheet rather than the roadmap: read twenty rows at random and check nothing serious was underweighted because it was written in two flat words.

If something is wrong, fix the prompt, not the output.
